# Runeforge

Runeforge — это игра в жанре tower defense, где вместо обычных башен используются магические руны.
Перед началом игры необходимо собрать комплект из пяти рун, которые можно размещать на поле, объединять и менять местами для создания мощных комбинаций
Продержитесь как можно дольше, зачищая всё более сложные волны врагов!

Игра сделана на C# и Windows Forms в качестве учебного проекта с установщиком и автоматической сборкой релизов через GitHub Actions.

## Скачать и запустить

1. Открыть страницу GitHub Releases
2. Скачать `RuneforgeSetup.exe` из последнего релиза.
3. Запустить установщик.
4. После установки открыть игру через ярлык `Runeforge` на рабочем столе или в меню "Пуск".

Установщик ставит игру в локальную папку пользователя и не требует прав администратора.

## Игровой процесс

- В начале игры выбирается комплект из 5 рун.
- Руны ставятся на поле и автоматически атакуют врагов.
- За убийство врагов начисляется энергия для создания новых рун и совершения действий.
- Одинаковые руны можно объединять, повышая их тир.
- Враги идут волнами, а каждая пятая волна является босс-волной.
- Если три врага пройдут через всё поле, игра завершается.

## Руны

В игре есть 24 руны:

`Kenaz`, `Isa`, `Fehu`, `Uruz`, `Thurisaz`, `Ansuz`, `Raidho`, `Gebo`, `Wunjo`, `Hagalaz`, `Nauthiz`, `Jera`, `Sowilo`, `Tiwaz`, `Berkano`, `Eiwaz`, `Perthro`, `Algiz`, `Ehwaz`, `Mannaz`, `Laguz`, `Ingwaz`, `Dagaz`, `Othala`.

Каждая руна имеет свои базовые параметры и отдельное поведение. Часть рун наносит прямой урон, часть усиливает соседей, замедляет врагов, создает эффекты, работает с добиванием или меняет экономику игры. Для балансировки игры была реализована система автоматической симуляции матчей: бот запускал сотни игровых сессий на различных комплектах рун, что позволило тестировать эффективность сборок, искать слишком сильные или слабые комбинации.

## Архитектура проекта

Внешне проект организован как MVC:

- `Models/` - состояние игры, сущности, компоненты, layout-модели интерфейса.
- `Views/` - отрисовка игрового мира, интерфейса, эффектов, рун, врагов и курсора.
- `Controllers/` - обработка ввода, управление игровым циклом, паузой, выбором билда и взаимодействием с полем.

Внутри симуляции используется простой гибридный подход, похожий на ECS:

- сущности хранят данные и компоненты;
- системы обновляют отдельные части игры;
- поведение рун вынесено в отдельные классы;
- настройки баланса лежат в `Configs/`.

Так структура остается понятной: форма запускает игру, контроллеры принимают ввод, модель хранит состояние, системы считают симуляцию, а views только рисуют результат.

## Структура проекта

- `Assets/` - изображения, шрифты, иконка приложения и визуальные эффекты.
- `Configs/` - параметры рун, врагов, волн, экономики и боссов.
- `Controllers/` - игровой цикл и пользовательское взаимодействие.
- `Effects/` - описание анимированных эффектов.
- `Factories/` - создание врагов и снарядов.
- `Models/` - состояние игры и игровые сущности.
- `Runes/` - отдельная логика поведения рун.
- `Systems/` - основные игровые системы симуляции.
- `Views/` - вся отрисовка.
- `Installer/` - конфигурация установщика Inno Setup.
- `.github/workflows/` - GitHub Actions pipeline для сборки релиза.
